# Bekjiri Next.js-Blog

Blog für M245 Aufgabe 7, gebaut mit Next.js nach dem offiziellen Tutorial.

Live: https://bekjiri-nextjs-blog.vercel.app

## Lokal starten

```bash
npm install
npm run dev
```

Danach läuft der Blog auf http://localhost:3000. Die Beiträge stehen in `content/posts.json`.

Das Formular «Neuer Beitrag» speichert nur lokal, weil das Dateisystem auf Vercel schreibgeschützt ist.
